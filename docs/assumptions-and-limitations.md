# Assumptions and Limitations

All seeded records are synthetic demonstration data. The platform does not claim access to ISRO data, ISRO validation, official ISRO methodology, or deployment in an ISRO environment. The linear forecast and residual interval are demonstration-grade methods that require domain calibration, uncertainty coverage checks, and independent engineering validation before operational use.

The managed web scaffold uses React, Express, tRPC, Drizzle, and SQL rather than the separate Python/FastAPI/PostgreSQL stack listed in the original prompt. This is an implementation constraint of the provided project environment. The analytical service remains isolated and deterministic, and the data model preserves the required reliability entities and traceability.
